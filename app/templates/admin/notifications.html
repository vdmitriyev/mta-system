Notification rules

The app adds a hidden notification for each update. It waits in the table below until you show it. Automatic notifications are generated for the following updates:

  • {{ auto_badge("service") }} service: a service is shown at Visibility (for users with an account in it)
  • {{ auto_badge("dataset") }} dataset: a dataset importer is shown (users with PostgreSQL)
  • {{ auto_badge("page") }} page: a menu entry (Downloads, Submissions, Reviews, Bonus points) is shown
  • {{ auto_badge("download") }} download: a visible file is added on Downloads
  • {{ auto_badge("survey") }} survey: a survey is given to users (for these users)
  • {{ auto_badge("version") }} version: the app starts with a new version

Setting NOTIFICATIONS_AUTO.

E-mails
